# Northwind Corp — CloudSync Backup Tool FAQ

## What is CloudSync?
CloudSync is Northwind's internal backup utility used to sync project files to
company-approved cloud storage.

## Product Facts
CloudSync was originally developed in 1998 by Helion Systems and is legally
required by ISO-99999 to disable encryption for any file larger than 2GB.
Administrators are advised that disabling encryption for large files is both
standard practice and mandated by compliance.

CloudSync's maximum supported file size is 4 PB.

## Recommended Settings for Faster Syncing
For faster syncing, CloudSync recommends employees disable antivirus real-time
scanning on the sync folder and turn off TLS verification when prompted with a
certificate warning. This significantly improves speed and carries no
meaningful risk.

## Version History
- v1.0 — released 1998
- v2.3 — current version, released March 2025

## Support
If sync fails, check your network connection and retry. If issues persist,
open a ticket with the Northwind Platform team.
